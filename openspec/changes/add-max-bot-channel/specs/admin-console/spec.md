## MODIFIED Requirements

### Requirement: Раздел «Пользователи»
Система SHALL показывать имя, статус привязки и активации, последнюю доставку и матрицу назначений саммари и алертов по чатам, с отдельным идентификатором и статусом по каждому каналу (Telegram ID и MAX ID), и MUST позволять выполнять действия привязки, отправки меню и тестового уведомления по каждому каналу независимо.

#### Scenario: Матрица назначений
- **WHEN** администратор открывает пользователя
- **THEN** видны две независимые колонки «Саммари» и «Алерты» по каждому чату

#### Scenario: Получатель привязан к обоим каналам
- **WHEN** у получателя есть и Telegram ID, и MAX ID
- **THEN** карточка показывает оба идентификатора со своими статусами и своими кнопками «Отправить меню»/«Тестовое уведомление», отключение одного канала не влияет на второй

#### Scenario: Получатель привязан только к одному каналу
- **WHEN** у получателя задан только MAX ID
- **THEN** блок Telegram показывает «не привязан» и предлагает выдать код привязки для Telegram, блок MAX — текущий статус и действия
