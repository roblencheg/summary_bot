## MODIFIED Requirements

### Requirement: Проверка прав на backend
Система SHALL требовать действующую сессию администратора для всех эндпоинтов `/api/*`, кроме входа, `/api/health`, `/api/ready`, webhook Telegram и webhook MAX, включая ручной запуск отчётов и повторные отправки.

#### Scenario: Запрос без сессии
- **WHEN** запрос к `/api/incidents` приходит без cookie сессии или с истёкшей сессией
- **THEN** система отвечает 401 и не выполняет действие

#### Scenario: Подделка запроса с чужого сайта
- **WHEN** изменяющий запрос приходит с заголовком `Origin`, не совпадающим с адресом приложения
- **THEN** система отвечает 403

#### Scenario: Webhook MAX без сессии
- **WHEN** запрос приходит на `/api/max/webhook` без cookie сессии администратора
- **THEN** система не требует сессию для этого пути и проверяет подлинность запроса собственным механизмом webhook MAX
