## MODIFIED Requirements

### Requirement: Минимизация контекста для AI
Система SHALL передавать в AI только тексты чата, роли авторов в виде меток и необходимый контекст и MUST NOT передавать идентификаторы получателей в любом канале (Telegram ID, MAX ID), настройки доступа и секреты.

#### Scenario: Содержимое запроса
- **WHEN** формируется запрос анализа
- **THEN** в нём нет данных о получателях и подписках ни по одному из каналов
