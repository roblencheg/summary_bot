# Саммари и «Что сейчас происходит» в формате rich-сообщений Telegram

## Why

В Telegram (Bot API 10.1) появились rich-сообщения: заголовки, таблицы, сворачиваемые блоки. Саммари сейчас — простой текст, разбитый на части «Часть i/n»; руководителю приходится листать несколько сообщений, а светофор и «Требует решения» читаются хуже таблицы. В rich-формате всё помещается в одно сообщение, а подробности по чатам свёрнуты.

## What Changes

- Саммари и «Что сейчас происходит» отправляются **одним rich-сообщением** (`sendRichMessage`, HTML): заголовок, «Обстановка» таблицей «⬤ / Чат / Что происходит», «Требует решения» таблицей «Кто / Где / Что / Статус», краткая картина списком, разделы чатов свёрнуты в `<details>`, легенда в подвале.
- Если сообщение не влезает в лимиты Telegram — сокращается список «кто с чем обращался» (20 → 10 → 5 → 0 на чат); если и так не влезает — используется прежний текстовый формат частями.
- **Запасной вариант:** если Telegram отклонил rich-сообщение (`bad_request`), отчёт отправляется прежним текстовым форматом частями; попытка записывается с кодом `rich_rejected`.
- Строка периода без часового пояса; у спокойных (🟢) чатов вместо фраз AI «инцидентов нет, тон нейтральный…» — «Инцидентов нет», в краткой картине они собраны одной строкой.
- Rich-версия отчёта хранится в `reports.rich_html` и показывается в веб-интерфейсе «как в Telegram».

- `on-demand-digest`: новое требование «Формат дайджеста».

## Impact

- БД (только добавление): `reports.rich_html TEXT`.
- Сервер: новый `services/summary-render.ts` (общая раскладка и rich-рендер), `ReportService.assemble/assembleOnDemand` возвращают `rich`, `DeliveryService.process` — отправка rich с запасным вариантом, `TelegramClient.sendRichMessage`.
- Фронтенд: просмотр отчёта показывает rich-версию.
